# **App Name**: TaskPilot

## Core Features:

- Dashboard: Display key metrics like Total Tasks, Completed Tasks, In Progress, and Overdue.
- Kanban Board: Visualize tasks in a Kanban-style board with columns: To Do, In Progress, Review, Done.
- Task Creation: Enable users to create new tasks with details like title, description, priority, due date, project, assignee, and tags using a modal form.
- Task Prioritization: Color-coded priority indicators for high, medium, and low priority tasks to quickly identify critical items.
- Task Assignment: Allow assigning tasks to multiple team members, displaying assignee initials on the task card.
- Smart Tagging: AI tool suggesting relevant tags based on task descriptions to categorize tasks efficiently.

## Style Guidelines:

- Primary color: Deep blue (#2962FF) to inspire focus and efficiency.
- Background color: Light blue (#E6EEFF), slightly desaturated, provides a calming backdrop.
- Accent color: Vivid purple (#9C27B0) to bring energy to key interactions.
- Body and headline font: 'Inter', a grotesque-style sans-serif for a modern, neutral feel.
- Sidebar navigation with a gradient layout grouping sections.
- Consistent use of simple, modern icons for navigation and task actions.
- Subtle transitions and animations on task updates and status changes.
